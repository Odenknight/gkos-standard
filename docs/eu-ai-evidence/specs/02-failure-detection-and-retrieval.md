# P1.2 — Failure detection and scoped retrieval

This specification placeholder covers the second implementation milestone of
the [P1 proposal](../P1_PROPOSAL.md), building on the valid dossier and revision
flow in P1.1. Introduce controlled cases for a wrong system-version reference,
changed evidence, missing files, and ambiguous or conflicting references, then
demonstrate retrieval of the declared review selection within an explicit
access scope. Each case should expose the relevant failure or limitation
without silently treating incomplete material as complete or disclosing
protected content. The intended outcome is a repeatable set of positive and
negative exercises with captured observations; detailed requirements,
interfaces, and acceptance checks will follow.
