# P1.3 — Review package and verification

This specification placeholder covers the third implementation milestone of
the [P1 proposal](../P1_PROPOSAL.md), using the dossier, retrieval workflow,
and failure exercises from P1.1 and P1.2. Assemble a small local review package
containing the selected material, a declared inventory and content bindings,
source and tool versions, and observed results. Demonstrate verification of
the intact package and detection of changed or missing inventoried files,
then provide runnable instructions and a short findings report separating
Standard-reference, Engine, and host/integration results and limitations.
Detailed package rules and acceptance checks will follow; this milestone
completes the proposed P1 sequence without expanding into P2 logging or P3
log instructions.
