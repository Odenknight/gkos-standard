# Informative domain guidance

September 15, 2026. Baseline: v0.81 plus explicitly identified development.
These guides are candidate applications, not adopted sector profiles,
regulatory mappings, qualification results or certifications.

The July feasibility composite is research input. The linked guides separate
its domains into bounded pilot questions. They are not exhaustive rewrites or
evidence that every sector obligation has been verified.

Before a pilot, select applicable permanent requirements from the
[registry](../../requirements/REGISTRY.md), freeze source and implementation
coordinates, and declare expected positive, negative, boundary and replay cases.
Publish failures, unsupported outcomes, burden and limitations. A passing subset
does not qualify a profile. Start with synthetic or appropriately public data.
