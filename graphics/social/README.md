# Social-preview graphics

These graphics are informative and non-normative. They are intended for
repository-sharing metadata, not as replacements for the master standard or
accepted development decisions.

| File | Source filename | Purpose | First reviewed release |
| --- | --- | --- | --- |

The master standard and accepted development decisions control whenever this
artwork differs from authoritative text. The artwork establishes no
certification, compliance, endorsement, implementation, or conformance claim.

Manual repository-settings action remains outstanding: configure
`gkos-social-card.png` as the GitHub social-preview image after reviewing its
rendering in the repository settings preview.

**Status, 2026-10-07 (proposed):** needs redesign before use as the current
preview. The card reads "Public pre-standard · v0.79". The current wording is
"developmental specification (public working draft)", and the current edition
is v0.82.1. The SVG source `gkos_social_card.svg` was never committed, so the
card cannot be rendered again from source. A redrawn card should be committed
as editable SVG, should omit the edition number, and should be exported with
sharp. See register entry GR-22 in the [graphics register](../REGISTER.md).
