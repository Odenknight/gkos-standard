## Working rhythm

1. Put rough thoughts in a dated file under `notes/`, using [the capture template](notes/CAPTURE_TEMPLATE.md) if helpful. A short paragraph is enough.
2. The coordinator preserves the original and extracts a brief, evidence needs, and tasks.
3. Assigned agents work on separate deliverables and leave messages in `mailbox/messages/`.
4. A reviewer checks claims against source records before the coordinator integrates drafts.
5. Shaun reviews the meaning, claims, and intended public content. Sending or publication requires authorization for that action.

The mailbox is file-based coordination, not a scheduler or running agent service. No background agents, reminders, external submissions, or publication were started by this setup.
