## Public evidence record

| Field | Meaning |
| --- | --- |
| evidence_id | Stable local identifier |
| event_kind | archive capture / deposit publication / release publication / other |
| event_at | Timestamp of the source's event, with timezone if known |
| observed_at | When you inspected it; never substitute this for event time |
| source_url | External record URL |
| artifact_url | Exact file or revision preserved, when available |
| sha256 | Hash of the actual preserved file; null when not available |
| match_basis | Exact bytes / exact visible clause / metadata only / unresolved |
| scope | Which claim or text is demonstrated by the record |
| limitations | Missing assets, mutable link, incomplete capture, self-declared date, etc. |

A landing-page capture may show project existence while proving nothing about a particular schema. A hash identifies bytes, not their publication time. A current copy's date is not retrospective proof. Record the earliest corroborated evidence for each contribution, not a single global date automatically assigned to all features.

## Recommended public characterization

Use “GKOS specifies [exact mechanism], documented in [exact version and clause]” when that content is verified. Use “The earliest public evidence located for this provision is [source/date]” only with corresponding evidence and search limits. Do not turn these into “first invented” without a substantially stronger investigation.
