COMMON GROUND — VISUAL PORTAL MOCK-UP

Open index.html in a modern browser. No install or server is required.
Dark mode is the default. The light/dark button remembers your choice in this browser.
All graphics, styling, and application code are embedded in index.html; no external graphics or libraries are needed. The network illustration scrolls horizontally on narrow screens to keep labels readable.

Included: desktop and mobile preview images, standalone HTML.
Deploy: upload index.html to a directory on your domain. HTTPS is recommended for hosting. Official program links require internet access.

Working prototype features: navigation, program and partner filters, four-stage preparation form, local draft saving, JSON exports, recovery records, approved-summary preview and withdrawal.
Boundaries: partner examples are fictional. No live matching, accounts, rights verification, messages, application submissions, or publication. Local browser storage is not secure document storage. Export drafts before changing browsers or devices.

Verified: navigation, filters, draft persistence, review, restricted/public boundaries, withdrawal, mobile overflow, and no JavaScript errors. Official guidance references are linked in the HTML. Prepared September 24, 2026.
